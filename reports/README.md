# Reports

Current mass-note status reports use:

```text
remnote-mcp-readiness-audit-*.json
remnote-mcp-readiness-audit-*.md
```

These reports distinguish local execution, static source readiness, and live-required proof. `PARTIAL` means source readiness exists but executable or live proof is still required.

Historical `remnote-mcp-live-audit-*` files created before 2026-06-20 were generated by the older static checker. Treat them as historical snapshots, not live RemNote proof.
